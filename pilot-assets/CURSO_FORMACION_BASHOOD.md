# MÓDULO 1: FUNDAMENTOS BLOCKCHAIN Y RWA

## 1.1 ¿Qué es Blockchain?

### Conceptos Básicos (30 min)

**Definición simple:**
> Blockchain es un libro contable digital, descentralizado e inmutable donde se registran transacciones de forma transparente y permanente.

**Características clave:**
- ✅ **Descentralización:** No hay un servidor central (ej: no existe "CEO de Bitcoin")
- ✅ **Transparencia:** Cualquiera puede ver las transacciones en un explorador
- ✅ **Inmutabilidad:** Lo que se escribe no se puede borrar ni modificar
- ✅ **Seguridad:** Protegido por criptografía y consenso distribuido

**Analogía práctica:**
```
Banco tradicional = Google Drive (1 servidor, puede cerrarse)
Blockchain = BitTorrent (miles de copias, nadie lo puede apagar)
```

### Componentes de una Blockchain (45 min)

1. **Bloques:**
   - Conjunto de transacciones agrupadas cada X minutos
   - Cada bloque está "encadenado" al anterior
   - Ejemplo: Bloque #19,234,567 contiene 150 transacciones

2. **Nodos:**
   - Computadoras que mantienen copia del blockchain
   - Validan nuevas transacciones
   - Base Blockchain tiene ~15,000 nodos validadores

3. **Smart Contracts (Contratos Inteligentes):**
   - Código que se ejecuta automáticamente cuando se cumplen condiciones
   - Ejemplo: "Si llega el día 25, distribuir €10,000 a los holders"
   - Una vez desplegado, nadie (ni el creador) puede modificarlo

4. **Tokens:**
   - Unidades digitales representando valor o activos
   - Ejemplo: 1 BHT-DX360 = 1/100,000 de la Excavadora Doosan DX360

### Ecosistemas Blockchain Relevantes (45 min)

| Blockchain | Características | Uso en Bashood |
|------------|-----------------|----------------|
| **Ethereum** | Primera con smart contracts | ❌ Gas fees muy altos ($50-200/tx) |
| **Polygon** | Layer 2 de Ethereum | ❌ Descartada (migración a zkEVM) |
| **Base** | Layer 2 Coinbase, EVM compatible | ✅ **ELEGIDA** (€0.01/tx, BackedBy) |
| **Arbitrum** | Layer 2 Ethereum optimista | 🟡 Alternativa futura |
| **Avalanche** | Layer 1 rápida | 🟡 Considerada inicialmente |

**¿Por qué Base?**
1. Costos ultra-bajos: €0.01 por transacción vs €50 en Ethereum
2. Respaldada por Coinbase (exchange #1 USA, regulado)
3. Compatible con Ethereum (mismo código, mismo ecosistema)
4. Rápida: 2 segundos vs 12 segundos Ethereum
5. Crecimiento explosivo: +500% TVL en 2024-2025

```solidity
contract BashoodToken {
    uint256 public totalSupply = 100_000 * 10**18;

        uint256 amountAfterFee = amount - fee;

        balances[to] += amountAfterFee;
        balances[TREASURY] += fee;
        
        emit Transfer(msg.sender, to, amountAfterFee);

}
```

### Validación Ingresos Declarados (45 min)

**Propietario declara: "Genero €15,000/mes con esta excavadora"**
**Tu job: VERIFICAR con data dura**

**Método cruce 3 fuentes:**
```

├─ Solicitar PDF facturas últimos 6 meses
├─ Subir a Excel: fecha, cliente, concepto, monto, IVA
├─ Calcular promedio mensual
├─ Identificar: ¿1 cliente 80%+ ingresos? (red flag diversificación)
└─ Varianza: ¿Estable o volátil? (CV <30% ideal)

Ejemplo Excel:

```

**FUENTE 2: EXTRACTOS BANCARIOS**
```
Solicitar: PDFs cuenta empresa últimos 6 meses

├─ ¿Hay gastos significativos? (combustible, reparaciones, seguro)
│  Anotar montos típicos mensuales
│
└─ ¿Saldo final positivo o negativo? (salud financiera)

Red flags bancarios:
🚩 Ingresos bank NO coinciden facturas (>10% diff)
🚩 Números redondos perfectos (posible manipulación)
```
