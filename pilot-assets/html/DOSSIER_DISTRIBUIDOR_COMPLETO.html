🏗️ 2. ¿QUÉ ES BASHOOD?

Plataforma de Tokenización de Activos Industriales

BASHOOD es una plataforma de tokenización de activos industriales que utiliza blockchain para crear un mercado eficiente, transparente y accesible de maquinaria de construcción avanzada.

Nuestra Misión:
Democratizar el acceso a tecnología de construcción sostenible (impresoras 3D industriales, robots multifuncionales, fábricas modulares) eliminando barreras financieras tradicionales.

Tecnología Base:

  • Blockchain: Base L2 (Coinbase infrastructure)
  • Estándar: BASHOOD-RWA-1 (ERC-721 extendido)
  • Almacenamiento: IPFS descentralizado
  • Oráculos: Chainlink integration para telemetría real-time

Descripción:

Incluye:

4.2 Plataforma Fractional Ownership

Descripción:
Permite comprar fracciones de activos industriales desde $100. Construye portfolio diversificado y recibe dividendos automáticos.

  • Reporting automático
  • Acceso global 50+ países

Descripción:
Alquila maquinaria tokenizada por periodos cortos (7-90 días) mediante smart contracts auto-ejecutables, sin trámites bancarios.
