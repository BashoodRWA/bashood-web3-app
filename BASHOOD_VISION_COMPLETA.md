## 🔥 COMISIONES DINÁMICAS BHT - SISTEMA DUAL

### Durante la Preventa (Fase 1):
```
Cada transferencia de BHT:
├─ 1% → QUEMA (burn)
└─ 5% → CONTRACT SHARE (acumulación en contrato)

Total fees: 6%
Propósito: Incentivar early investors
```

### Después de la Preventa (Fase 2 - Permanente):
```
Cada transferencia de BHT:
├─ 0.1% → QUEMA (burn)
└─ 0.5% → CONTRACT SHARE

Total fees: 0.6%
Propósito: No castigar el largo plazo
```

### Implicaciones:

**Durante preventa (fees altos 6%):**
- ✅ Incentiva holdear hasta fin de preventa
- ✅ Castiga a flippers/especuladores
- ✅ Acumula fondos en contract para proyecto
- ✅ Burn agresivo reduce supply temprano

**Después de preventa (fees bajos 0.6%):**
- ✅ Facilita trading normal
- ✅ No penaliza pagos/comercio
- ✅ Burn sostenido a largo plazo
- ✅ Contract share mínimo para mantenimiento

## 🔧 IMPLEMENTACIÓN TÉCNICA CORREGIDA

### Cambios Necesarios en Smart Contracts:

#### 1. BashoodToken.sol - Fees Dinámicos

```solidity
// AGREGAR: Sistema de fees dual

bool public presaleActive = true;

// Fees durante preventa
uint256 public constant PRESALE_BURN_RATE = 100;      // 1%
uint256 public constant PRESALE_CONTRACT_SHARE = 500; // 5%

// Fees post-preventa
uint256 public constant POST_BURN_RATE = 10;           // 0.1%
uint256 public constant POST_CONTRACT_SHARE = 50;      // 0.5%

function transfer(address to, uint256 amount) public override returns (bool) {
    uint256 burnRate = presaleActive ? PRESALE_BURN_RATE : POST_BURN_RATE;
    uint256 shareRate = presaleActive ? PRESALE_CONTRACT_SHARE : POST_CONTRACT_SHARE;
    
    uint256 burnAmount = (amount * burnRate) / 10000;
    uint256 shareAmount = (amount * shareRate) / 10000;
    uint256 sendAmount = amount - burnAmount - shareAmount;
    
    if (burnAmount > 0) _burn(msg.sender, burnAmount);
    if (shareAmount > 0) _transfer(msg.sender, contractShareWallet, shareAmount);
    
    _transfer(msg.sender, to, sendAmount);
    return true;
}

function endPresale() external onlyOwner {
    presaleActive = false;
    emit PresaleEnded(block.timestamp);
}
```
