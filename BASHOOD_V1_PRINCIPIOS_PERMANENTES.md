## 📌 DECLARACIÓN FUNDACIONAL

Bashood se estructura como **protocolo de tokenización descentralizado con governance comunitaria.**

Estos principios NO son aspiracionales. Son lindes jurídicos que protegen la viabilidad a 10 años.

---

## 🎯 LOS 5 PRINCIPIOS

### 1️⃣ CERO DERECHOS ECONÓMICOS AUTOMÁTICOS

**Principio:**
```
BHT NUNCA otorgará:
- Dividends automáticos
- Revenue share automático
- Staking yield automático
- Derecho a treasury distribution automática
- Rendimiento garantizado de ningún tipo
```

**¿Qué SÍ puede haber?**
```
✅ Treasury gestionado por DAO (votación comunitaria)
✅ Si DAO vota distribuir, lo decide con 2/3 supermayoría
✅ Distribución NO es derecho, es decisión DAO
✅ Puede ser 0%, puede ser 1%, lo decide la comunidad
```

**¿Qué NO puede haber?**
```
❌ Fórmula automática (X% de fees van a holders)
❌ Promesa de "incentivos" que parezcan yield
❌ Acuerdos ocultos con inversores sobre "returns"
❌ Marketing que sugiera "upside económico"
```

**Violación = Cambio de directiva o governance replanteado**

---

### 2️⃣ GOVERNANCE REAL O NO HAY

**Principio:**
```
La DAO no es ceremonial. Es el poder real.
```

**¿Qué significa?**
```
✅ Decisiones críticas requieren votación comunitaria:
   - Cambios en fee structure
   - Upgrades de contratos
   - Asignación de treasury
   - Cambios de parámetros económicos

✅ 1 BHT = 1 voto (sin whale override)

✅ Votaciones con quórum mínimo (25%+) y supermayoría (50%+)

✅ Timelock: 48 horas entre votación y ejecución
```

**¿Qué está prohibido?**
```
❌ Founder/Admin ejecuta cambios sin votación
❌ Multisig executor sin DAO aprobación
❌ "Emergency admin" absoluto
❌ Cambios de parámetros económicos sin DAO
```

**Violación = Exit de core team o replaneo governance**

---

### 3️⃣ SEPARACIÓN CLARA: TOKEN ≠ ACTIVOS

**Principio:**
```
BHT y los activos RWA tokenizados son INDEPENDIENTES económicamente.
```

**¿Qué significa?**
```
✅ Precio de BHT NO depende de performance de activos RWA

✅ NFTs representan acceso al marketplace, no derecho a activos

✅ "Treasury" de protocolo ≠ "Fonds de inversión"

✅ Documentación NUNCA vincula "compra de BHT" con "ganancia de activos"
```

**¿Qué está prohibido?**
```
❌ "Compra BHT → Participas en ganancias de casas 3D"
❌ "Token sube porque los activos generan rendimiento"
❌ "Holders reciben % de ingresos de activos"
❌ Treasury invertida en activos (fondo fiduciario)
```

**Violación = Reposicionamiento completo o reclasificación como security**

---

### 4️⃣ UTILIDAD TÉCNICA REAL, NO ESPECULATIVA

**Principio:**
```
BHT tiene utilidad funcional. No es un token especulativo.
```

**¿Cuál es la utilidad?**
```
✅ Governance: 1 BHT = 1 voto en decisiones DAO

✅ Descuentos funcionales: 
   - Sin BHT: 2.5% fee en transacciones
   - Con 100k BHT: 2.0% fee (0.5% descuento funcional)
   - (NO es "reward de trading", es descuento de servicio)

✅ Acceso a parámetros beta (early access a nuevas features)

✅ Participación en fee reduction votes (cada titular vote)
```

**¿Qué NO es utilidad?**
```
❌ "Su valor va a subir"
❌ "Por tener BHT ganas dinero"
❌ "Acceso a oportunidades de inversión"
❌ "Participación en ganancias de proyecto"
```

**Violación = Reescritura de whitepaper o cambio de narrativa**

---

### 5️⃣ TRANSPARENCIA RADICAL: CÓDIGO = VERDAD

**Principio:**
```
Lo que dice el código debe alinearse 100% con la narrativa.
Si hay contradicción: el código gana.
```

**¿Qué significa?**
```
✅ Auditoría externa ANTES de presale (semana 2)

✅ Code review verifica:
   - NO hay mecanismo oculto de profit-sharing
   - Treasury es controlado por DAO (multisig + timelock)
   - Burn mechanism está hardcoded y visible
   - No hay "upgrade backdoor" para cambiar términos

✅ Todo parámetro contractual es inmutable O votable por DAO

✅ Publicación de auditoría pre-sale (no after)
```

**¿Qué está prohibido?**
```
❌ "Confianza en el team" vs "Código verificado"
❌ Upgradeable contracts sin DAO guard
❌ Parámetros mutables por founder
❌ Mecanismos ocultos (relay patterns, proxies no auditadas)
```

**Violación = Rescisión de investor lockups y reputacional damage**

## ⚖️ CÓMO APLICAR ESTOS PRINCIPIOS

### Decisión de inversión
```
Antes de cualquier cambio:
"¿Viola alguno de estos 5 principios?"
- SÍ → No se hace. Punto.
- NO → Vota la DAO, ejecuta si aprueba
```

### Presión de mercado (common case)
```
"¿Queremos agregar staking yield para competir?"
→ Viola principio 1
→ Respuesta: NO. O pivotea el proyecto entero bajo estos 5 principios.
```

### Presión de inversores
```
"¿Podemos prometer 5% APY para la presale?"
→ Viola principios 1, 2, 4
→ Respuesta: NO. Buscamos inversores alineados con Camino 2, no Camino 3.
```

### Tención económica
```
"El treasury tiene $5M, ¿por qué no distribuimos a holders?"
→ Legítimo debate. Se vota.
→ Si DAO vota 50%+ a favor → se distribuye (pero no es "derecho automático")
→ Si DAO vota en contra → se quema o reinvierte
```
